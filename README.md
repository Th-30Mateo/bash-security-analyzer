# Bash Security Analyzer

Repositorio de práctica orientado al aprendizaje de Bash scripting y a la futura automatización de comprobaciones relacionadas con la seguridad en sistemas Linux.

## Objetivo

Desarrollar progresivamente un script que permita automatizar comprobaciones del sistema y presentar sus resultados de forma clara.

## Tecnologías previstas

- Bash
- Linux
- Terminal y herramientas del sistema
- Git y GitHub

## Estado del proyecto

**En desarrollo.** El script `analyzer.sh` todavía no contiene una implementación funcional del análisis. Por lo tanto, este repositorio no debe utilizarse como herramienta de auditoría ni considerarse un analizador de vulnerabilidades operativo.

## Próximos pasos

- Implementar las comprobaciones que realizará el script.
- Validar las entradas y los permisos necesarios.
- Manejar errores de ejecución.
- Presentar resultados de forma legible.
- Probar el comportamiento en un entorno Linux controlado.
- Documentar cada comprobación implementada y sus limitaciones.

## Aviso

Este repositorio tiene fines educativos. No afirma detectar vulnerabilidades ni sustituye herramientas profesionales de auditoría de seguridad.
